# 功能清单

按模块列出当前实现的能力，便于对照与二次开发。

## 对话

- 流式输出、停止、重新生成、多版本切换
- 深度思考
  - 输入框下方开关
  - 设置 →「思考过程展示」：折叠 / 展示 / 仅展示最新部分（默认）
  - 「仅展示最新部分」默认收起并显示 6 行预览（最新内容贴底），点标题展开完整内容，再点收起
- 联网搜索（`deepseek_web_search` 工具）
- Markdown / 代码高亮 / KaTeX / Mermaid
- 每条回复右下角显示「输入 x · 输出 x · 金额 ¥x」，回复结束后自动刷新余额（token 过千用 k，保留一位小数）
- 金额按官方价格表估算，区分高峰与空闲时段，分缓存命中 / 未命中 / 输出计价
  - 高峰：北京时间周一至周五 09:00–12:00、14:00–18:00；其余时段（含周末）为空闲
  - 法定节假日暂无日历数据，按工作日近似
  - 金额右侧「?」点击显示气泡「仅供参考，以实际为准」
- 模型选择（设置 → 通用设置）
  - 按可用凭证筛选：登录账号后出现「账号 · Flash / Pro」，配置 API Key 后出现「API Key · Flash / Pro」
  - 账号模型排在前面并优先使用；未配置 API Key 时不出现 API Key 模型
  - 两者都没有时提示「请先登录账号或配置 API Key」
- 推理强度（`none / low / high / max`）
- 最大输出长度（默认 / 4K / 8K / 16K / 32K）

## 输入与附件

- 快捷面板（输入框「+」）
  - 第一行：相册最近照片
  - 第二行：拍照 / 相册 / 文件
- 最近照片多选
  - 点一下即加入草稿并上传
  - 再点一下取消并移除
  - 选中态与草稿附件双向同步（删除缩略图也会取消勾选）
- 系统相册多选（`ACTION_OPEN_DOCUMENT` + `EXTRA_ALLOW_MULTIPLE`）
- 附件缩略图
  - 右上角删除按钮常驻
  - 点击全屏预览
  - 预览页右下角「编辑」进入圈画，确认后替换原附件
- 语音输入（按住说话）
  - 按住麦克风开始录音，松手结束并转写
  - 按住时上滑一段距离取消本次输入，录音期间在按钮旁显示「上滑取消」提示
  - 原生 `AudioRecord` 录音（16kHz 单声道），失败自动回退网页录音
  - 走官方 `POST /v1/tools/asr`
  - 录满 120 秒自动停止并转写

## 圈画标注

- 全屏编辑器，底色跟随亮 / 暗主题
- 固定蓝色画笔 `#0a84ff`，粗细为滑块的 25%（12/40）
- 顶部：关闭（X）· 撤销 · 重做 · 裁切
  - 撤销 / 重做为「掉头箭头」图标，居中排布
  - 裁切激活时按钮高亮
- 右下角确认（√）
- 裁切模式：拖动四角调整范围，底部提供「取消 / 应用裁切」
- 双指缩放 + 平移，缩放范围 1×–5×
- 多指按下立即结束当前笔画，不会在两指之间画线

## 账号与计费

- Harness 账号登录（OAuth PKCE + 本机回环回调）
- 登录后侧边栏底部显示头像、昵称与余额
  - 已登录 + 有 API Key：分两行显示「账号 ¥x」「API ¥x」
  - 未登录 + 有 API Key：显示 API 余额，并提示「点击此处登录账号」
  - 已登录 + 无 API Key：显示账号余额（合并赠送金额）
- 设置 → 数据管理：账户余额与 API 余额两张卡片，各自刷新并显示充值 / 赠送明细
- 余额查询带超时：API 余额 8 秒、账号余额 10 秒，失败显示「获取失败」
- 余额刷新：启动一次、每次回复完成后一次、每分钟一次（后台跳过）
- 设置 → 数据管理 →「账户充值」跳转官方充值页
- 账号通道下无需填写 API Key 即可对话
- 支持手动填写 API Key

## 数据管理

- 导入官方导出 ZIP（容错：单条不兼容只跳过）
- 导出为官方格式 ZIP（分块写入系统「下载」）
- 导入 / 导出进度条（百分比 + 已处理数量）
- 删除全部对话（二次确认）

## 体验与适配

- 侧边栏宽度 300px，拖动时跟手推开主界面（拉出多少显示多少，两者位移同源、全程无缝）
  - 拉出 ≥25% 松手展开，否则回弹收起；展开状态下反向拖动同样跟手
  - 拖动中被系统打断（来电、下拉通知栏）时按当前位移自动收口
  - 移动端点空白处或左滑关闭；桌面端收起入口在左下角
- 抽屉常驻挂载、只做位移：滚动位置由浏览器保持，反复开合不会回到顶部
- 搜索命中后打开侧边栏，自动滚动到该会话并居中
- 搜索框聚焦时键盘只覆盖、不挤压窗口，底部输入框不会被顶起
- 侧边栏顶部只保留搜索框（去掉应用名标题），搜索框独占整行
- 会话置顶：「⋯」菜单置顶 / 取消置顶，顶部「置顶」分组永远在最前，带一条浅分割线
- 多选：「⋯」菜单进入多选，可批量置顶 / 取消置顶 / 删除（删除二次确认）
- 设置页支持左右滑动切换「通用设置 / 数据管理」，选项卡高亮与滑动同步
- 设置面板从屏幕底部上滑打开、下滑关闭
- 加号面板：打开时输入框先上移、内容随后浮现，按钮旋转 45° 变叉号；收起 150ms
- 点击输入框自动收起加号面板，键盘与面板不同时出现
- 返回键 / 侧滑返回逐级关闭：全屏预览 → 关于 → 设置 → 侧边栏 → 搜索 → 编辑器 / 附件预览 / 加号面板 → 退出
- 内容不侵入状态栏；键盘弹出时输入框上移
- 暗色模式 / 跟随系统（原生读取系统夜间模式并通知网页），分段选项卡切换
- 字体大小四档（0.85 / 0.95 / 1.05 / 1.15，默认 0.95）
- 启动免责门槛：权限用途说明、免责声明、开源仓库地址；不同意退出应用，同意后进入
- 首次使用引导（欢迎 → 权限申请 → 登录 / API Key → 导入 → 完成），可逐步跳过
  - 引导页按钮贴屏幕四角：跳过右上、上一步左下、下一步右下
- 运行时权限在引导页逐项申请，启动与免责页不申请任何权限
- 固定官方 DeepSeek 标识（鲸鱼图标、标语、应用名与桌面图标）
- 关于软件：开发者、项目、版本号、免责声明，支持从 GitHub 检查更新
- 启动检查更新：发现新版本可立即更新 / 稍后 / 跳过此版本
- WebView 调试开关（默认关闭，开启需确认风险）
- 输入框回车换行，仅点击发送按钮才发送
- 生成期间唤醒锁，退后台不中断；回前台自动续写
- 会话列表增量渲染（首屏 40 条）
- 侧边栏历史搜索（区分「我 / AI」角色）
- 余额刷新：启动一次、每次回复完成后一次、每分钟一次（页面在后台时跳过）
