# 功能清单

按模块列出当前实现的能力，便于对照与二次开发。

## 对话

- 流式输出、停止、重新生成、多版本切换
- 深度思考
  - 输入框下方开关
  - 设置 →「思考过程展示」：折叠 / 展示 / 仅展示最新部分（默认）
  - 「仅展示最新部分」限高约 6 行，最新内容贴底，框内可滚动查看
- 联网搜索（`deepseek_web_search` 工具）
- Markdown / 代码高亮 / KaTeX / Mermaid
- 每条回复右下角显示「输入 x · 输出 x · 金额 ¥x」，回复结束后自动刷新余额（token 过千用 k，保留一位小数）
- 模型选择（设置 → 通用设置）
  - `API Key · DeepSeek-V4.1-Flash`
  - `API Key · DeepSeek-V4-Pro`
  - `账号 · DeepSeek-V4.1-Flash`
  - `账号 · DeepSeek-V4-Pro`
- 推理强度（`none / low / high / max`）
- 最大输出长度（默认 / 4K / 8K / 16K / 32K）

## 输入与附件

- 快捷面板（输入框「+」）
  - 第一行：相册最近照片
  - 第二行：拍照 / 相册 / 文件
- 最近照片多选
  - 点一下即加入草稿并上传
  - 再点一下取消并移除
  - 选中态与草稿附件双向同步（删除缩略图也会取消勾选）
- 系统相册多选（`ACTION_OPEN_DOCUMENT` + `EXTRA_ALLOW_MULTIPLE`）
- 附件缩略图
  - 右上角删除按钮常驻
  - 点击全屏预览
  - 预览页右下角「编辑」进入圈画，确认后替换原附件
- 语音输入（按住说话）
  - 按住麦克风开始录音，松手结束并转写
  - 按住时上滑一段距离取消本次输入
  - 原生 `AudioRecord` 录音（16kHz 单声道），失败自动回退网页录音
  - 走官方 `POST /v1/tools/asr`
  - 录满 120 秒自动停止并转写

## 圈画标注

- 全屏编辑器，底色跟随亮 / 暗主题
- 固定蓝色画笔 `#0a84ff`，粗细为滑块的 25%（12/40）
- 顶部：关闭（X）· 撤销 · 重做 · 裁切
  - 撤销 / 重做为「掉头箭头」图标，居中排布
  - 裁切激活时按钮高亮
- 右下角确认（√）
- 裁切模式：拖动四角调整范围，底部提供「取消 / 应用裁切」
- 双指缩放 + 平移，缩放范围 1×–5×
- 多指按下立即结束当前笔画，不会在两指之间画线

## 账号与计费

- Harness 账号登录（OAuth PKCE + 本机回环回调）
- 登录后侧边栏底部显示头像、昵称、余额
- 设置页余额卡片：总余额 + 充值 / 赠送明细，可手动刷新
- 账号通道下无需填写 API Key 即可对话
- 支持手动填写 API Key

## 数据管理

- 导入官方导出 ZIP（容错：单条不兼容只跳过）
- 导出为官方格式 ZIP（分块写入系统「下载」）
- 导入 / 导出进度条（百分比 + 已处理数量）
- 删除全部对话（二次确认）

## 体验与适配

- 侧边栏平移推开主界面，支持左右滑动开合
- 设置页支持左右滑动切换「通用设置 / 数据管理」
- 返回键 / 侧滑返回逐级关闭：全屏预览 → 关于 → 设置 → 侧边栏 → 搜索 → 编辑器 / 附件预览 / 加号面板 → 退出
- 内容不侵入状态栏；键盘弹出时输入框上移
- 暗色模式 / 跟随系统（原生读取系统夜间模式并通知网页）、字体大小、界面缩放
- 主题切换：官方主题（DeepSeek 标识 / 标语 / 桌面图标与名称同步）与大肥鱼主题，默认官方
- 关于软件：开发者、项目、版本号、免责声明，支持从 GitHub 检查更新
- 输入框回车换行，仅点击发送按钮才发送
- 生成期间唤醒锁，退后台不中断；回前台自动续写
- 会话列表增量渲染（首屏 40 条）
- 侧边栏历史搜索（区分「我 / AI」角色）
